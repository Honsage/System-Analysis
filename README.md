# System Analysis

Репозиторий содержит проекты по анализу и проектированию информационных систем и программных продуктов.

## ИС Парикмахерская

Информационная система "Парикмахерская" предназначена для автоматизации процесса управления небольшим предприятием (салоном красоты).

[Проект ИС](./ИС%20Парикмахерская/README.md)

## Веб-приложение Didacticum

Didacticum – это веб-приложение для создания, просмотра и распространения интерактивных образовательных материалов.

[Проект приложения](./Веб-приложение%20Didacticum/README.md)

## Десктоп-приложение Мои Финансы

Мои Финансы – это настольное приложение, представляющее собой автоматизированную систему для учета личных финансовых операций и проведения анализа денежных потоков.

[Проект приложения](./Десктоп-приложение%20Мои%20Финансы/README.md)

## Инструментальное ПО GitPM

GitPM представляет собой автоматизированную систему для комплексного управления локальными Git проектами.

[Проект приложения](/Инструментальное%20ПО%20GitPM/README.md)

## Веб-мессенджер Teamon

Teamon – браузерный мессенджер для организации совместной работы внутри команды в процессе реализации проектов.

[Проект мессенджера](/Веб-мессенджер%20Teamon/README.md)
