# Перечень пользовательских историй продукта Teamon

| № | Кто? | Что хочет? | С какой целью? |
|---|------|------------|----------------|
| 1. | Руководитель команды | Создать чат команды | Обеспечить пространство для коммуникации |
| 2. | Участник команды | Обсудить работу над проектом | Узнать или подсказать решение проблемы |
| 3. | Руководитель команды | Обсудить достигнутые результаты и запланировать новые задачи в формате созвона | Организовать процесс работы над проектом |
| 4. | Руководитель команды | Назначить ответственного за задачу | Обеспечить выполнение задач проекта |
| 5. | Пользователь мессенджера | Детально обсудить общие вопросы с другим пользователем | Получить или предоставить решение вопроса |
| 6. | Участник команды | Поделиться документом, связанным с проектом | Выполнить поставленную задачу или предоставить свое видение вопроса |
| 7. | Участник команды | Зафиксировать выполнение поставленной задачи | Отчитаться о проделанной работе |
| 8. | Участник команды | Найти сообщение в истории переписки | Сослаться на информацию или вспомнить результат обсуждения |
| 9. | Участник команды | Получать уведомление при его упоминании в чате | Чтобы своевременно среагировать на важное событие |
| 10. | Участник команды | Узнать полезную информацию, связанную с проектом | Принять взвешенное решение или уточнить концепцию |
| 11. | Участник команды | Закрепить важное сообщение | Обеспечить быстрый доступ к важной информации |
