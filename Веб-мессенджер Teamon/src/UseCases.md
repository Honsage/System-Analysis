# Прецеденты использования системы Teamon

| Наименование прецедента | Главная последовательность | Альтернативная последовательность |
|--------------------------|----------------------------|------------------------------------|
| Зарегистрироваться в мессенджере | 1. Зайти на страницу регистрации<br>2. Ввести учетные данные для регистрации<br>3. Подтвердить регистрацию | 1. Зайти на страницу регистрации<br>2. Ввести учетные данные для регистрации<br>3. Пользователь уже существует |
| Создать командный чат | 1. Нажать кнопку создания чата<br>2. Выбрать пользователей мессенджера по id<br>3. Указать название чата | 1. Нажать кнопку создания чата<br>2. Выбрать пользователей мессенджера по email<br>3. Указать название чата |
| Отправить сообщение в чат | 1. Открыть чат<br>2. Напечатать сообщение<br>3. Нажать кнопку отправки | – |
| Закрепить сообщение в чате | 1. Открыть чат<br>2. Выбрать сообщение<br>3. Нажать кнопку закрепления | – |
| Организовать созвон | 1. Открыть панель созвонов<br>2. Нажать кнопку звонка | 1. Открыть панель созвонов<br>2. Выбрать участников<br>3. Нажать кнопку звонка |
| Загрузить файл в область проекта | 1. Перейти в панель файлов<br>2. Выбрать файл через файловый менеджер<br>3. Подтвердить прикрепление файла | 1. Перейти в панель файлов<br>2. Перетащить файл при помощи drag-and-drop<br>3. Подтвердить прикрепление файла |
| Просмотреть файлы проекта | 1. Открыть панель файлов | – |
| Скачать файл из области проекта | 1. Открыть панель файлов<br>2. Загрузить файл | – |
| Создать задачу на доске | 1. Открыть доску для задач<br>2. Создать новую задачу<br>3. Назначить ответственного за задачу | 1. Открыть доску для задач<br>2. Создать новую задачу<br>3. Оставить ответственным себя (по умолчанию) |
| Изменить статус задачи | 1. Открыть доску для задач<br>2. Перетащить задачу в нужный столбец | – |
