# Спецификация прецедентов использования платформы Doceum 

## Роли пользователей

В системе определены следующие основные роли пользователей:

- **Администратор** – лицо, осуществляющее общее управление платформой, модерацию публикаций и управление учетными записями пользователей;
- **Автор** – пользователь системы, создающий, редактирующий и публикующий интерактивные документы;
- **Читатель** – пользователь системы, который просматривает опубликованные документы и работает с ними (скачивает, добавляет в избранное, проверяет подпись);
- **Гость** – неавторизованный пользователь, имеющий ограниченный доступ к функциональности платформы.

## Таблица 1 – Описание прецедентов

| Идент. | Наименование | Актор | Предусловие | Основной поток |
|----|--------------|-------|-------------|----------------|
| **UC-1** | Регистрация в системе | Гость | Пользователь находится на странице регистрации | 1. Пользователь вводит учетные данные<br>2. Система валидирует данные<br>3. Система создает новую учетную запись |
| **UC-2** | Вход в систему | Администратор, Автор, Читатель | Пользователь не аутентифицирован | 1. Пользователь вводит учетные данные<br>2. Система выполняет аутентификацию<br>3. Пользователь перенаправляется в личный кабинет |
| **UC-3** | Создание интерактивного документа | Автор | Пользователь авторизован как Автор | 1. Автор открывает редактор<br>2. Создает новый документ<br>3. Система сохраняет документ как черновик |
| **UC-4** | Редактирование документа | Автор | Документ существует и принадлежит Автору | 1. Автор выбирает документ из списка<br>2. Открывает его в редакторе<br>3. Вносит изменения<br>4. Система сохраняет документ |
| **UC-5** | Публикация документа | Автор | Документ находится в статусе «Черновик» | 1. Автор выбирает документ<br>2. Инициирует публикацию<br>3. Система публикует документ и делает его общедоступным |
| **UC-6** | Просмотр опубликованного документа | Читатель, Гость | Документ опубликован | 1. Пользователь открывает документ по ссылке<br>2. Система рендерит документ |
| **UC-7** | Скачивание документа | Читатель | Документ опубликован | 1. Пользователь открывает документ<br>2. Нажимает кнопку «скачать»<br>3. Система предоставляет файл документа |
| **UC-8** | Поиск опубликованных документов | Читатель, Гость | Пользователь находится на странице поиска | 1. Пользователь вводит поисковый запрос<br>2. Система отображает подходящие результаты |
| **UC-9** | Добавление документа в избранное | Читатель | Пользователь авторизован | 1. Пользователь открывает документ<br>2. Добавляет его в избранное |
| **UC-10** | Просмотр локального документа | Читатель, Гость | У пользователя есть файл интерактивного документа | 1. Пользователь открывает страницу просмотра документа<br>2. Загружает файл документа<br>3. Система рендерит содержимое документа |
| **UC-11** | Проверка подписи документа | Читатель, Гость | Документ открыт | 1. Пользователь инициирует проверку подписи<br>2. Система выполняет верификацию<br>3. Отображает результат проверки |
| **UC-12** | Управление публикациями | Администратор | Пользователь авторизован как Администратор | 1. Администратор переходит в раздел модерации<br>2. Инициирует действия над публикациями (снятие, возврат)<br>3. Система выполняет действия |
| **UC-13** | Управление пользователями | Администратор | Пользователь авторизован как Администратор | 1. Администратор открывает список пользователей<br>2. Инициирует действия над пользователями (блокировка, подтверждение учетки)<br>3. Система выполняет действия |

---

**Примечания:**

- **Актор** – действующее лицо, взаимодействующее с системой
- **Предусловие** – условие, которое должно быть выполнено до начала выполнения сценария
- **Основной поток** – последовательность действий при успешном выполнении сценария
