# Пояснительная записка к эскизному проекту ИС УДС

## 1. Общие положения

### 1.1. Полное наименование системы и ее условное обозначение

Наименование системы: Автоматизированная информационная система учета деятельности дошкольного образовательного учреждения.

Условное обозначение: УДС (Учет Деятельности Сада).

### 1.2. Номер договора

Шифр темы: АИС-УДДОУ.

Работы по созданию Системы ведутся на основании Договора подряда №04-ИС/2026 от 12.02.2026.

### 1.3. Ремарка

Данный эскизный проект представляет собой усеченную версию пояснительной записки к эскизному проекту и схему функциональной структуры Системы.

## 2. Описание процессов деятельности объекта автоматизации

Объектом автоматизации является организационно-педагогическая деятельность ДОУ, включающая процессы учета сведений об обучающихся и сотрудниках, контроля посещаемости, ведения коррекционной работы и документооборота.

Назначением Системы УДС является автоматизация организационно-методического и кадрового учета, а также информационное обеспечение педагогической деятельности ДОУ.

Вид автоматизируемой деятельности – информационный учет и делопроизводство.

Система предназначена для решения следующих задач:

- централизованное хранение и обработка данных об обучающихся и сотрудниках ДОУ;
- цифровизация рутинных операций по учету посещаемости и календарному планированию;
- автоматизация подготовки отчетности и внутренней документации на основе шаблонов;
- обеспечение единого и контролируемого доступа к информации для всех категорий сотрудников.

## 3. Основные технические решения

### 3.1. Решения по структуре АС и ее подсистем

УДС представляет собой комплексную систему и состоит из следующих подсистем.

**Подсистема обработки документов** предназначена для автоматизации документооборота путем генерации документов по шаблонам и извлечения данных из документов. Используется руководством ДОУ и делопроизводителем.

**Подсистема учета посещаемости** обеспечивает цифровизацию процесса фиксации посещаемости воспитанников и предотвращает дублирование информации. Используется воспитателями, профильными и коррекционными специалистами.

**Подсистема учета коррекционной работы** предназначена для автоматизации учета сведений о коррекционном развитии воспитанников, а также о результатах ППК. Используется коррекционными специалистами.

**Подсистема библиотеки методических материалов** предназначена для хранения и предоставления методических материалов: конспектов занятий, планов, учебных пособий и проч. Может использоваться всеми сотрудниками ДОУ, но преимущественно воспитателями и руководителями.

**Подсистема объявлений** предназначена для информирования пользователей Системы о событиях ДОУ. Доступна руководству для публикации, всем остальным ролям для просмотра.

**Подсистема управления пользователями** предназначена для обеспечения учетных записей пользователей системы и назначения ролей. Используется руководством.

**Подсистема представления данных** предназначена для предоставления структурированных данных по запросу. Например, сведений о ребенке, сотруднике или группе. Может использоваться всеми внутренними пользователями, а также родителями.

**Подсистема работы с хранилищем данных** предназначена для выполнения CRUD операций с БД и управления ее состоянием (масштабированием и резервным копированием). Используется администратором.

### 3.2. Решения по взаимодействию подсистем

**Связь «Подсистема управления пользователями» – «Подсистема представления данных»** определяет процесс фильтрации выходных данных: в зависимости от роли пользователя (воспитатель, специалист, руководство, родитель) подсистема представления данных отображает только разрешенное подмножество информации о детях, сотрудниках и группах.

**Связь «Подсистема управления пользователями» – «Подсистема учета посещаемости»** определяет доступность функций учета посещаемости: воспитатель может отмечать детей своей группы, специалист – детей, с которыми работает, руководство – просматривать сводки по всему учреждению.

**Связь «Подсистема управления пользователями» – «Подсистема учета коррекционной деятельности»** определяет разграничение доступа к данным ППК: сотрудники коррекционного блока (логопед, психолог, дефектолог) имеют право вносить и просматривать заключения в соответствии со спецификой своей деятельности.

**Связь «Подсистема управления пользователями» – «Подсистема библиотеки методических материалов»** определяет права на загрузку и удаление материалов: старший воспитатель и методисты могут пополнять библиотеку, воспитатели – просматривать и скачивать.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема управления пользователями»** определяет процесс сохранения учетных данных пользователей, их ролей, а также сверку данных при аутентификации.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема представления данных»** определяет процесс агрегации данных из БД для предоставления специфических структурированных сведений по запросу пользователя.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема учета посещаемости»** определяет процесс записи истории посещаемости в базу данных и последующего чтения этих данных для отображения журнала и формирования сводок.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема учета коррекционной деятельности»** определяет процесс сохранения заключений ППК и карт коррекционной работы, а также их загрузку для просмотра специалистами.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема библиотеки методических материалов»** определяет процесс загрузки метаданных материалов в базу и материалов в файловое хранилище, а также их получение при поиске и просмотре.

**Связь «Подсистема работы с хранилищем данных» – «Подсистема объявлений»** определяет процесс сохранения текстов объявлений и прикрепленных файлов, а также их извлечение для отображения ленты.

**Связь «Подсистема представления данных» – «Подсистема учета посещаемости»** определяет процесс отображения в карточке воспитанника сводной информации о его посещаемости.

**Связь «Подсистема представления данных» – «Подсистема учета коррекционной деятельности»** определяет процесс отображения в карточке воспитанника заключений ППК и отметок о коррекционной работе.

**Связь «Подсистема обработки документов» – «Подсистема представления данных»** определяет процесс получения актуальных данных карточек детей и сотрудников для заполнения шаблонов документов (списки, приказы, справки).
